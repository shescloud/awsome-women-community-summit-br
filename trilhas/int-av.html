Além do Pipeline: Arquiteturas de CI/CD para Escala, Segurança e Engenharia de Plataforma

Samantha Chiachio

A automação básica de build e deploy tornou-se uma commodity, mas escalar pipelines em arquiteturas de microsserviços complexas exige ir muito além de scripts lineares. Nesta palestra avançada, transcenderemos o trivial "commit-test-deploy" para explorar a fronteira da Engenharia de Plataforma. Discutiremos como arquitetar fluxos robustos utilizando padrões de GitOps para garantir a imutabilidade da infraestrutura e estratégias de Progressive Delivery (como Canary e Blue-Green) para desacoplar o deploy da release e mitigar riscos em produção. Aprofundaremos na segurança da cadeia de suprimentos de software (Supply Chain Security), demonstrando o uso de SBOMs e assinatura de artefatos para garantir integridade do código à nuvem. Por fim, abordaremos a observabilidade do próprio pipeline, ensinando como instrumentar processos para extrair métricas DORA reais e transformar seu servidor de CI em um motor de entrega contínua resiliente e orientado a dados

Arquitetura Inclusiva: Como Unificar Observabilidade na AWS Sem Caos e Sem Sobrecarga

Leticia Albuquerque

Arquitetura Inclusiva é uma abordagem para unificar telemetria em ambientes AWS complexos - múltiplas contas, clusters, formatos e pipelines - sem gerar caos operacional ou sobrecarga cognitiva. Nesta sessão, apresento uma arquitetura para projetar ingestão, normalização, enriquecimento e visualização usando Amazon Managed Grafana, Amazon Managed Prometheus, CloudWatch Logs, Timestream, Kafka e OpenTelemetry. Também demonstrarei exemplos reais de configurações que aplicam esses padrões. Ao final, os participantes terão clareza sobre como tomar decisões arquiteturais que reduzem custo, eliminam redundâncias e tornam observabilidade realmente operável em larga escala.

Migração de Console AWS para Terraform: Do Zero ao Estado com Infraestrutura como Código

Cami Martins

Esta palestra detalha o processo essencial para modernizar ambientes AWS migrando infraestrutura gerenciada manualmente (via AWS Console) para um estado totalmente controlado pelo Terraform. Vamos desmistificar a transição, apresentando um workflow robusto e prático para transformar recursos existentes em código versionável, auditável e altamente reprodutível. Vamos ver questões como: Reverse-Engineering de Infraestrutura: Como utilizar o Terraformer para importar recursos AWS existentes, gerando o código .tf e o arquivo de estado (.tfstate) automaticamente. Refatoração Inteligente: Técnicas para modularizar e limpar o código gerado pelo Terraformer, usando o Terraform Search como um acelerador para garantir a sintaxe e a configuração corretas. Controle de Versão (GitOps): Estabelecer o GitHub como a única fonte de verdade (Single Source of Truth), integrando o código Terraform para colaboração, branching, estados do Terraform e revisões via Pull Requests. Assumindo o Controle: Como executar o terraform plan e apply de forma segura após a importação, garantindo que o Terraform assuma o controle da infraestrutura sem causar downtime ou alterações não intencionais. Iceberg + Athena: o match perfeito para processamento analítico de alto desempenho

Amanda Kunath e Heloisa Escobar

Com a evolução dos data lakes, formatos de tabelas abertas se tornaram essenciais para garantir performance, governança e flexibilidade. Apache Iceberg vem se consolidando como um padrão para arquiteturas lakehouse, e quando combinado com Amazon Athena, possibilita consultas analíticas avançadas sem a necessidade de gerenciar clusters. Nesta palestra, vamos compartilhar como projetar e operar tabelas Iceberg na AWS utilizando Glue Catalog e Athena, explorando conceitos como time travel, schema evolution e particionamento inteligente. A partir de experiências reais, discutirei estratégias para melhorar performance, reduzir custos de leitura e evitar armadilhas comuns que impactam negativamente o consumo de dados. Vamos abordar decisões de arquitetura, boas práticas e aprendizados do mundo real para quem deseja extrair o máximo de valor de data lakes modernos usando tecnologias serverless.

Assistente GenAI com Bedrock usando StepFunctions, OpenSearch e RAG

Leticia Massae Uchida

A apresentação aborda o uso de StepFunctions, múltiplos modelos do Bedrock e OpenSearch para implementar um assistente online baseado em GenAI. Este assistente auxilia os clientes com informações sobre cursos (engenharia, medicina, arquitetura e muitos outros). Ao final da conversa, o assistente cria um resumo e o envia para a SalesForce como um lead, e a equipe comercial pode usar as informações para entrar em contato com o cliente. Esta arquitetura permite respostas de conteúdo específico ou privado, proporcionando interações de baixa latência.
